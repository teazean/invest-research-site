# 创新药行业术语表

更新日期：2026-08-10

| 术语 | 小白解释 | 投资含义 |
|---|---|---|
| 靶点 | 药物要干预的生物学对象 | 靶点被验证不代表具体分子有效，热门靶点还会拥挤 |
| 临床I/II/III期 | 从初步安全、概念验证到大规模确证 | 阶段越后成功概率通常越高，但成本和失败损失也更大 |
| 主要终点 | 试验事先约定的核心胜负标准 | 事后挑亚组或次要终点不能替代主要终点成功 |
| 标准治疗（SoC） | 当前医生通常采用的对照方案 | SoC不断进步会抬高后发药物的疗效门槛 |
| IND/NDA/BLA | 临床申请、化学药上市申请、生物药上市申请 | 受理或递交不等于批准，更不等于商业成功 |
| ADC | 抗体偶联药，把载荷送到特定细胞 | 价值取决于靶点、连接子、载荷、剂量和治疗窗的组合 |
| 双抗/多抗 | 一个药物同时结合两个或多个靶点 | 可能增强疗效，也可能增加毒性和制造复杂度 |
| CMC | 化学、生产和质量控制 | 决定药物能否稳定放大、获批和持续供应 |
| License-out | 把某区域或全球开发销售权授权给伙伴 | 应拆首付款、里程碑、版税和成本义务，不能只看总包 |
| 首付款 | 签约后通常较快支付的不可退金额 | 比远期里程碑更接近真实现金，但仍可能附交割条件 |
| 里程碑 | 达到临床、审批或销售条件才支付的钱 | 必须按条件和成功概率折现，不能全额当收入 |
| 版税 | 按未来净销售额一定比例支付 | 依赖对手商业化能力、专利期和合同扣减条款 |
| CRO/CDMO | 研发服务和工艺/生产外包 | 客户承担药物成败，服务商主要承担订单、利用率和回款风险 |
| 现金跑道 | 现有现金按当前消耗还能支撑多久 | 少于12个月通常意味着融资和稀释风险上升 |
| rNPV | 对各阶段成功概率调整后的净现值 | 比给亏损Biotech套PE更合适，但高度依赖概率与峰值销售假设 |
| 峰值销售 | 产品成熟期可能达到的年销售上限 | 应由患者数、渗透率、净价和治疗时长拆解，不能拍脑袋 |
| 净价 | 扣除医保谈判、返利和渠道折扣后的实际价格 | 目录价增长不等于公司真实收入增长 |
| 自由现金流 | 经营现金流扣除资本开支后的现金 | 比毛利率更接近股东可分配价值，但药企还要持续研发 |
| DAR | ADC平均每个抗体连接的药物数量 | 太低可能疗效不足，太高可能稳定性和毒性恶化 |
| PPQ | 商业生产前用于证明工艺持续稳定的验证批次 | PPQ数量比早期项目更接近商业化生产机会 |
| IOPV | ETF盘中的参考净值 | 可用于看折溢价，但跨境休市和汇率会让它滞后 |
| QDII | 境内基金投资境外资产的制度安排 | 带来汇率、时差、额度和海外休市风险 |
| HTA | 卫生技术评估，比较疗效、成本和预算影响 | 影响药物能否进入公共支付以及可接受净价 |
| CRDMO | 从药物研发到生产的一体化外包 | 项目可随阶段转化，但订单与药物成功都不是锁定的 |
| Biotech/Biopharma | 以前者偏研发资产、后者偏已有产品和商业能力的行业称呼 | 不是严格会计分类，应以真实收入和现金流判断 |
| EV/峰值销售 | 企业价值除以预计成熟期销售额 | 适合早期粗筛，不能替代成功率和时间折现的rNPV |
| 正常化PE | 剔除一次性授权、减值和异常费用后的市盈率 | 用于盈利平台，必须公开剔除项目和可持续利润假设 |
