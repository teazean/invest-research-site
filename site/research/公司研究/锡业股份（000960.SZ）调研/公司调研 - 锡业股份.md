## 1. 一句话看懂公司

锡业股份是全球最大的精锡生产商之一，既采矿，也把自有和外购精矿冶炼成锡、铜、锌、铟等金属卖给电子焊料、化工、工业材料客户。客户付钱买的是符合纯度标准、可追溯、能稳定大批量交付的金属。按经济机制，自有资源和多金属综合回收理论上比外购矿冶炼、供应链贸易更容易保留利润；但公司没有披露矿山/冶炼/副产品分部净利润，所以这只是利润来源假设，不是已验证结论。

最重要的理解是：**锡价上涨不等于公司利润等比例上涨。** 2025年公司锡精矿自给率仅28.47%，大量原料需要外购；锡价上涨一方面抬高自产矿利润，另一方面也抬高外购精矿、库存和套保保证金需求。2025可量化的现金占用主要是存货和经营性应收，预付款增量并不大。最终利润取决于自产矿量、原料采购折扣/加工费、多金属回收、冶炼效率和套保，而不是只看盘面锡价。

### 1.1 小白术语

| 词 | 白话解释 | 本文怎么用 |
|---|---|---|
| 精矿 | 矿石选矿后富集的原料，还不是可直接使用的金属 | 自产精矿越多，公司越能保留矿山利润 |
| 精锡/锡锭 | 冶炼提纯后的标准金属产品 | 主要卖给焊料、化工和合金客户 |
| 自给率 | 冶炼所需原料中来自自己矿山的比例 | 低自给意味着锡价上涨也会推高采购成本 |
| 加工费 | 冶炼厂替矿山把精矿变成金属所赚的加工收益 | 矿紧时加工费可能下降，冶炼量大不一定利润高 |
| 综合回收 | 从同一批复杂矿中回收锡、铜、锌、铟、金银等 | 多卖一种金属，就能摊薄单位处理成本 |
| 套保/保证金 | 用期货锁定部分价格风险；交易所要求先交资金担保 | 能降低价格风险，也会占用现金 |
| 归母/扣非 | 归母是归属于母公司股东的利润；扣非剔除报废、处置等特殊项目 | 两者并看，避免把一次性项目误当经营能力 |
| CFO/FCF | CFO是经营现金流；本文FCF代理=CFO-资本开支 | 检查账面利润是否真正变成现金 |
| TTM/正常化利润 | TTM是最近12个月；正常化是跨周期更可能持续的利润 | 周期股不能只拿高价阶段利润算便宜 |
| 永续债 | 会计上可计入权益、经济上先于普通股获得分派的融资 | 表面净资产并不全属于普通股 |
| 资源租 | 低成本、稀缺矿权因金属价格高于开采成本而产生的超额收益 | 只有公司真正拥有并低成本开采资源时才留在股东手里 |
| 升贴水 | 实际成交价相对交易所基准价多收或少收的部分 | 可帮助判断品牌和地区是否带来客户溢价 |
| 成本曲线 | 把全球生产者按每吨成本从低到高排列 | 越靠左越能承受金属价格下跌 |
| ROIC | 投入一元经营资本产生多少税后经营利润 | 判断扩矿、收购和冶炼扩建是否真正创造价值 |
| 压力测试/安全垫 | 用更差假设看损失；安全垫是估值和价格间预留余地 | 需要用户回报目标，不能由作者随意设成真理 |

### 技术成熟度与发展趋势

采矿、选矿和火法/湿法冶炼都是成熟工业技术，竞争不在“能不能做”，而在复杂多金属矿能否以更高回收率、更低能耗、更稳定质量和更少环保停机持续运行。行业衡量水位应看矿石品位、采选回收率、冶炼综合回收率、单位现金成本、能耗、杂质控制、开工率、环保合规和产品认证。公司没有充分公开逐矿、逐炉同口径指标，因此只能确认规模化工程能力，不能声称每项工艺全球领先。

未来1-3年趋势是低碳冶炼、数字化矿山、再生锡、复杂二次资源回收和供应链可追溯。它们会降低单位成本或提高可销售金属量，只有当客户采购、单吨成本和现金利润得到验证，才构成竞争优势。

**竞争优势结论：** 已验证的事实是公司拥有矿权、较大资源量、全球头部精锡产量和完整采选冶链；“客户因此选择它”“成本因此低于竞对”“优势持续转成高现金利润”均缺同口径证据，只能定为正在形成或竞争优势假设。不能据此直接说公司已经拥有经充分验证的护城河，更不能推出脱离交易所价格的强定价权。
